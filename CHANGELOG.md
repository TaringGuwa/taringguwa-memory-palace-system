Changelog

[0.0.5] — Timing & Interface Update

Added

- Added a three-level audio feedback system based on the user's response time:
  - Beep 1: response time below 1 second.
  - Beep 2: response time between 1 and 2 seconds.
  - Beep 3: response time above 2 seconds.

Changed

- Updated the mnemonic representation for number 2:
  - Previous: Barack Obama
  - New: SpongeBob
- Updated the mnemonic representation for number 4:
  - Previous: Daendels
  - New: Mr. Bean
- Updated the mnemonic representation for number 5:
  - Previous: Albert Einstein
  - New: John Wick

Improved

- Removed the "Correct" and "Incorrect" buttons that previously appeared after generating a random number.
- Simplified the interaction flow after number generation.

Version Status

Version 0.0.5 — Development

This version focuses on improving response-time feedback, mnemonic representations, and the overall interaction flow.
